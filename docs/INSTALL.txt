Redstone Trail 0.3.2
Minecraft Java Edition 26.2 / Fabric

1. Minecraft 26.2용 Fabric Loader 0.19.5 이상을 설치합니다.
2. 해당 게임 프로필의 mods 폴더에 redstone-trail-0.3.2.jar와 26.2용 Fabric API 0.160.0+26.2 이상을 넣습니다. 이전 Redstone Trail JAR는 교체하세요.
3. 게임에서 /rt로 메뉴를 엽니다.
4. 계속 남는 경로: 기록 시작 → 회로 작동 → 기록 정지. 이미 그려진 경로는 유지됩니다.
5. 일시적 경로: 별도 '일시적 트레일: 꺼짐' 버튼을 눌러 켭니다. 기록 시작을 누를 필요가 없습니다.
6. 두 기능을 동시에 켤 수 있습니다. 기록 정지·기록 경로 초기화는 일시적 기능에 영향을 주지 않습니다. 일시적 기능을 끄면 일시적 경로만 지웁니다.
7. 계속 유지 경로의 외형은 '선·색·투명도', 일시적 외형·소멸 시간·방식은 '일시적 트레일 설정'에서 바꿉니다.
8. 비교용 임시 저장은 계속 유지 경로만 복사합니다. 저장한 트레일에서 여러 경로를 함께 표시하고 각각 수정·숨기기·삭제할 수 있습니다.
9. Mod Menu 20.0.3과 Text Placeholder API 3.1.0-beta.1+26.2를 함께 설치하면 모드 목록의 Redstone Trail에서 아이콘·설명과 설정 버튼을 볼 수 있습니다. 둘 다 선택 사항이며 없어도 /rt로 사용할 수 있습니다.

하나의 모드 JAR에 두 기능이 모두 들어 있습니다. 서버, Show Interaction, Feedback Flag 설치는 필요하지 않습니다.
Java 25 이상이 필요합니다. 다른 Minecraft 버전, Forge/NeoForge, Bedrock은 지원하지 않습니다.
-sources.jar는 개발용이며 mods 폴더에 넣지 않습니다.

기본 반경은 64블록입니다. 계속 유지 기록은 시작 위치, 일시적 트레일은 현재 플레이어 위치를 중심으로 작동합니다.
범위 안의 모든 블록 상태 변화를 기록합니다. 서버가 전송하지 않은 변화와 상태값이 없는 고체 블록의 통전은 추적할 수 없습니다.
월드/서버별 경로와 설정은 config/redstone_trail/worlds에 저장됩니다.
일시적 켜기·끄기와 외형·시간 설정은 복원되지만 일시적 경로 자체는 재접속 때 복원하지 않습니다.
