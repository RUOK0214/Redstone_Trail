# 검증 기록

검증일: **2026-10-30 (한국 시간)** · 버전: **0.2.0**

## 0.2.0 외형·다중 비교·일시적 트레일

모델 및 저장 자동 검사:

- 0.1.0 자료의 경로·반경·표시 설정 보존, 기본 외형과 계속 유지 모드로 이전.
- 현재 경로의 외형 변경과 저장본의 외형 변경이 서로 독립적임.
- 현재 경로 초기화 후 모든 저장본 보존, 선택한 저장본만 숨김/삭제, 저장·재읽기 후 이름/색/투명도/두께/표시 복원.
- 저장본 개수 한도에서 기존 자료 유지, 잘못된 색/두께 설정 거부.
- 세 소멸 방식의 시작·중간·정확한 만료 경계·만료 후 추가 페이드 시점 검사.
- 앞선 작동부터 소멸, 재작동한 블록만 시간 갱신, 기록 정지·숨김 후에도 시간 경과.
- 기존 경로에서 일시적 모드로 전환할 때 시간 시작, 계속 유지로 바꾸면 남은 경로 보존, 이미 만료한 경로를 되살리지 않음.
- 사용자 투명도와 시간 페이드의 곱셈, 투명도 100%에서 완전히 숨김.
- 비교용 저장본은 자동 소멸하지 않으며, 일시적 현재 경로는 파일 재읽기 때 복원하지 않음.

실제 Minecraft 클라이언트 자동 검사와 화면 확인:

- 현재 경로의 RGB 코드 입력·투명도·선 두께 조절, 적용 전 초안 유지, 작은 창으로 크기 변경 후 적용.
- 이미 그린 윤곽선이 변경한 색/투명도/두께로 표시됨. 잘못된 색 코드는 적용 버튼 비활성화.
- 실제 서버 블록 변화로 만든 두 트레일을 각각 다른 색으로 저장하고 함께 렌더링. 같은 위치는 윤곽 크기를 달리해 겹친 색 구분.
- 현재 경로를 숨겨도 저장본 둘은 표시됨. 저장본 A의 이름/외형 변경이 즉시 기존 윤곽선에 적용됨.
- 저장본 개별 숨기기/보이기, 삭제 취소/확인. 다른 저장본과 현재 경로는 유지됨.
- 일시적 설정 화면의 모드·소멸 방식 선택과 적용. 한국어 설정/목록/외형 화면을 854×480에서 확인.
- 세 방식 각각 실제 서버 블록 변화를 기록해 소멸까지 확인. 두 페이드 방식에서 실제 렌더링 자료의 알파 감소 확인.
- 기록 정지 후 현재 경로가 만료해도 저장본은 표시됨. 새 관리 객체로 파일 재읽기 후 저장본과 설정 복원.

스크린샷은 `docs/screenshots/appearance-small-ko.png`, `comparison-world-ko.png`,
`saved-trails-small-ko.png`, `temporary-settings-small-ko.png`에 있습니다.

## 환경

- Windows / Java 25 / Gradle 9.5.1
- Minecraft Java 26.2 / Fabric Loader 0.19.5 / Fabric API 0.160.0+26.2
- 별도 생성한 개발용 싱글플레이 테스트 월드
- OpenGL / NVIDIA RTX 3060 / 1000×700 및 854×480 창

## 기본 기능 회귀 검사

`gradlew.bat build --offline --no-daemon`:

- 기록 시작 전/정지 후 변화 무시, 정지 후 위치 보존, 다시 시작하면 누적.
- 구형 반경 경계 포함/바깥 제외, 다른 차원 제외.
- 동일 위치 반복 변화 합산.
- 8,192개 한도에서 새 위치 수집 정지, 오래된 표식 보존.
- JSON 저장·재읽기, 표시 설정 복원, 복원 시 기록 정지.
- 월드 식별자별 파일 분리, 손상 파일 보존과 유효하지 않은 자료 거부.

`gradlew.bat runClientGameTest --offline --no-daemon`:

- 실제 Minecraft 시작, Mixin 적용, 월드 진입.
- 회로 준비 중 기록이 생기지 않음.
- `/rt` 명령어로 메뉴 진입, 한국어 기록 시작 버튼을 클릭하면 기록을 시작하고 게임으로 복귀.
- **실제 마우스 우클릭으로 레버 작동**. 레버·가루 4개·램프에 대한 서버 상태 갱신으로 여섯 위치 모두 기록.
- 신호를 껐을 때 램프의 추가 변화가 감지되고 기존 위치 유지.
- 기록 정지 버튼을 누른 뒤 100틱이 지나도 여섯 윤곽 유지. 정지 후 새 블록 변경은 수집하지 않음.
- 저장 후 관리 객체를 새로 만들어 파일을 다시 읽어도 기록 개수와 윤곽 형상이 복원되고 기록은 정지 상태.
- 초기화 확인창의 취소는 기록 보존, 확인은 기록과 렌더링 형상을 제거.
- 한국어 메뉴와 작은 창의 버튼·문구 배치, 신호가 꺼진 월드의 윤곽선을 스크린샷으로 확인.

스크린샷: `docs/screenshots/`. 실제 게임 결과이며 예시 자료로 만든 이미지가 아닙니다.

## 아직 확인하지 않은 범위

- 외부 멀티플레이 서버의 지연·거절·보호 구역, 재접속 및 차원 이동의 실제 입력 전체 흐름.
- 모든 종류의 피스톤·중계기·비교기·관찰자 회로, 게임 재시작을 포함한 사용자 프로필의 직접 설치.
- 8,192개 윤곽의 최악 부하, 모든 GUI 배율, 다른 렌더링 모드·셰이더·Vulkan.
- 저장 권한 거절/디스크 부족의 실제 게임 환경.

재접속 복원은 저장 모델과 실제 게임 내 새 관리 객체로 검증했습니다. 게임 프로세스를 재시작한 실기 검증으로 간주하지 않습니다.
개발용 인증 계정의 Realms/프로필 키 경고, Windows 성능 카운터 경고와 기본 그래픽 옵션 경고가 있었으나 모드 검사는 통과했습니다.
