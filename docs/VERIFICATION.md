# 검증 기록

검증일: **2026-10-30 (한국 시간)** · 버전: **0.1.0**

## 환경

- Windows / Java 25 / Gradle 9.5.1
- Minecraft Java 26.2 / Fabric Loader 0.19.5 / Fabric API 0.160.0+26.2
- 별도 생성한 개발용 싱글플레이 테스트 월드
- OpenGL / NVIDIA RTX 3060 / 1000×700 및 854×480 창

## 통과한 검사

`gradlew.bat build --offline --no-daemon`:

- 기록 시작 전/정지 후 변화 무시, 정지 후 위치 보존, 다시 시작하면 누적.
- 구형 반경 경계 포함/바깥 제외, 다른 차원 제외.
- 동일 위치 반복 변화 합산.
- 8,192개 한도에서 새 위치 수집 정지, 오래된 표식 보존.
- JSON 저장·재읽기, 표시 설정 복원, 복원 시 기록 정지.
- 월드 식별자별 파일 분리, 손상 파일 보존과 유효하지 않은 자료 거부.

`gradlew.bat runClientGameTest --offline --no-daemon`:

- 실제 Minecraft 시작, Mixin 적용, 월드 진입.
- 회로 준비 중 기록이 생기지 않음.
- `/rt` 명령어로 메뉴 진입, 한국어 기록 시작 버튼을 클릭하면 기록을 시작하고 게임으로 복귀.
- **실제 마우스 우클릭으로 레버 작동**. 레버·가루 4개·램프에 대한 서버 상태 갱신으로 여섯 위치 모두 기록.
- 신호를 껐을 때 램프의 추가 변화가 감지되고 기존 위치 유지.
- 기록 정지 버튼을 누른 뒤 100틱이 지나도 여섯 윤곽 유지. 정지 후 새 블록 변경은 수집하지 않음.
- 저장 후 관리 객체를 새로 만들어 파일을 다시 읽어도 기록 개수와 윤곽 형상이 복원되고 기록은 정지 상태.
- 초기화 확인창의 취소는 기록 보존, 확인은 기록과 렌더링 형상을 제거.
- 한국어 메뉴와 작은 창의 버튼·문구 배치, 신호가 꺼진 월드의 윤곽선을 스크린샷으로 확인.

스크린샷: `docs/screenshots/`. 실제 게임 결과이며 예시 자료로 만든 이미지가 아닙니다.

## 아직 확인하지 않은 범위

- 외부 멀티플레이 서버의 지연·거절·보호 구역, 재접속 및 차원 이동의 실제 입력 전체 흐름.
- 모든 종류의 피스톤·중계기·비교기·관찰자 회로, 게임 재시작을 포함한 사용자 프로필의 직접 설치.
- 8,192개 윤곽의 최악 부하, 모든 GUI 배율, 다른 렌더링 모드·셰이더·Vulkan.
- 저장 권한 거절/디스크 부족의 실제 게임 환경.

재접속 복원은 저장 모델과 실제 게임 내 새 관리 객체로 검증했습니다. 게임 프로세스를 재시작한 실기 검증으로 간주하지 않습니다.
개발용 인증 계정의 Realms/프로필 키 경고, Windows 성능 카운터 경고와 기본 그래픽 옵션 경고가 있었으나 모드 검사는 통과했습니다.
