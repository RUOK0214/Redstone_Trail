# 검증 기록

검증일: **2026-10-30 (한국 시간)** · 버전: **0.4.1**

## 선택한 아이콘 적용

- 사용자가 선택한 버튼 → 가루 → 중계기 → 램프 아이콘을 수정 없이 적용.
- 선택 원본과 모드 리소스의 SHA-256 일치 확인. 배포 JAR의 아이콘 경로와 이미지 포함 여부 확인.
- 실제 Mod Menu의 영어·한국어 목록에서 새 아이콘 표시 확인.
- 빌드·모델 검사와 Mod Menu 포함 클라이언트 검사를 재실행. Mod Menu 없는 환경의 검증은 기능 코드가 동일한 0.4.0 결과를 유지.

## 공통 설정과 반경 512

- 기록 반경 버튼이 128 → 256 → 512로 변경되며 모델은 16~512의 지원 값을 검증.
- 512블록 구형 범위의 세 축 경계 포함, 513블록 및 구형 범위 밖 대각선 제외. 계속 유지와 일시적 수집 모두 검사.
- 공통 설정 파일의 외형·반경·표시·일시적 켜기·시간·소멸 방식 저장 및 재읽기.
- 새 월드에는 설정만 이어지고 기록 좌표·비교용 저장본·기록 중 상태는 이어지지 않음.
- 기존 월드의 예전 설정보다 최신 공통 설정을 적용하며, 해당 월드의 경로와 저장본 개별 외형은 보존.
- 손상되었거나 null인 공통 설정 파일은 덮어쓰지 않고 읽기 실패로 처리.
- 실제 게임에서 반경 512를 선택하고 플레이어보다 약 219블록 높은 위치의 서버 블록 변경을 기록. 기존 192블록 제한 밖의 윤곽 형상 생성 확인.
- 실제 서로 다른 싱글플레이 월드 A → B → A 이동 검사: 설정 전파, 경로 분리, B에서 변경한 설정이 A로 이어짐.
- 여러 월드가 메모리에 남아 있을 때 자동 저장이 예전 설정을 되살리지 않음. 관리 객체 재생성 후에도 공통 설정과 월드별 기록 복원.

화면: `docs/screenshots/radius-512-ko.png`, `shared-settings-world-b-ko.png`.
최대 512블록의 경계는 모델로 검사했고 실제 서버 갱신은 약 219블록 거리에서 검사했습니다.
512블록 전체의 청크 로딩·최대 규모 회로 부하는 별도 실기 미검증입니다.

## Mod Menu 설명·아이콘·설정 연결

- Mod Menu 20.0.3 / Text Placeholder API 3.1.0-beta.1+26.2에서 전용 PNG 아이콘과 영어·한국어 설명 표시.
- 실제 Mod Menu 목록에서 Redstone Trail을 선택하고 설정 버튼을 눌러 연결 검사.
- 월드 진입 전에는 사용 안내 표시, 완료 버튼으로 원래 Mod Menu에 복귀.
- 월드 안에서는 기존 경로 메뉴 표시. 완료/Escape로 Mod Menu 복귀, 기록 시작은 게임으로 복귀하며 기록 시작.
- Mod Menu를 포함한 환경에서 기존 기록·저장·비교·윤곽 크기·소멸 기능의 실제 게임 검사 통과.
- `runClientGameTest -PwithoutModMenu --offline --no-daemon`으로 Mod Menu와 Text Placeholder API 없는 환경에서도 기존 게임 검사 통과.
- 배포 JAR는 Mod Menu와 Text Placeholder API를 포함하거나 필수로 요구하지 않음.

화면: `docs/screenshots/modmenu-ko.png`, `modmenu-title.png`, `modmenu-world-required.png`.
아이콘 원본 경로와 생성 기록: [ICON.md](ICON.md).

## 독립 작동과 동시 표시

`gradlew.bat build --offline --no-daemon`의 모델·저장 검사를 통과했습니다.

- 둘 다 꺼짐, 계속 유지 기록만, 일시적 트레일만, 둘 다 켜짐의 네 상태.
- 기록 시작 없이 일시적 수집. 계속 유지 기록 정지·숨김·초기화 후에도 일시적 수집과 소멸 유지.
- 일시적 끄기가 해당 경로만 비우고 계속 유지 기록·저장본을 보존함.
- 일시적 만료 후 같은 위치의 계속 유지 경로와 비교용 저장본 보존.
- 계속 유지 기록의 고정 중심과 일시적 기능의 이동 중심, 반경·차원별 수집 범위.
- 각 경로의 외형 독립성, 비교용 저장에 계속 유지 위치만 포함됨.
- 계속 유지 8,192개 한도에서 해당 기록만 정지하고 일시적 기능은 계속 동작.
- 일시적 8,192개 한도에서 가장 오래전에 작동한 위치부터 교체하고 재작동 위치는 보존.
- 세 소멸 방식의 시작·중간·정확한 만료 경계·추가 페이드 시점, 재작동한 위치의 시간 갱신.
- 사용자 투명도와 소멸 투명도의 곱셈, 설정 변경 시 이미 만료한 위치가 되살아나지 않음.
- 저장 형식 3의 외형·시간·켜기 상태·경로 복원. 일시적 위치는 저장하지 않고 계속 유지 기록은 정지 상태로 복원.
- 0.1.0 경로·표시 설정과 0.2.0의 계속 유지 경로·시간 설정·비교본 이전.
- 0.2.0의 선택식 일시적 설정은 새 토글이 꺼진 상태로 이전되며, 이전 일시적 위치를 계속 유지 경로로 바꾸지 않음.
- JSON 저장·재읽기, 월드별 파일 분리, 손상 파일 보존과 잘못된 자료 거부.

`gradlew.bat runClientGameTest --offline --no-daemon`의 실제 게임 검사를 통과했습니다.

- 기록이 정지된 상태에서 메인 메뉴의 일시적 버튼을 켜고 서버의 새 블록 변화를 수집.
- 기록 시작 후 두 경로에 각각 누적. 기록 정지 후에도 일시적 경로는 새 변화를 수집.
- 기록 경로 초기화 뒤 일시적 경로와 비교본 보존.
- 기록 중 일시적 버튼을 끄면 일시적 경로만 제거되고 이후 계속 유지 기록은 정상 누적.
- 세 방식 모두 실제 서버 변화부터 소멸까지 검사. 두 페이드 방식은 렌더링 자료의 알파 감소도 검사.
- 일시적 경로 만료 뒤에도 같은 위치의 계속 유지 경로가 렌더링되며 기록 상태 유지.
- 일시적 설정의 별도 색·투명도·두께 편집이 계속 유지 외형에 영향을 주지 않음.
- 일시적 설정 적용만으로 켜기·끄기 상태가 바뀌지 않음.
- 새 관리 객체로 파일을 재읽을 때 계속 유지 경로·비교본·설정은 복원하고 일시적 위치는 비어 있음.
- 한국어 메뉴·설정의 배치를 854×480 창에서 스크린샷으로 확인.

관련 화면: `docs/screenshots/both-running-small-ko.png`, `temporary-on-recording-off-ko.png`,
`recording-on-temporary-off-ko.png`, `temporary-settings-small-ko.png`.

## 기존 기능 회귀 검사

- 실제 Minecraft 시작과 Mixin 적용, 별도 테스트 월드 진입.
- 회로 준비 중 경로가 생기지 않음.
- `/rt` 메뉴의 한국어 기록 시작 버튼을 클릭하면 기록을 시작하고 게임으로 복귀.
- **실제 마우스 우클릭으로 레버 작동**. 레버·가루 4개·램프의 서버 갱신으로 여섯 위치 모두 기록.
- 신호를 끈 뒤에도 기존 위치 유지 및 램프의 추가 변화 감지.
- 기록 정지 후 100틱이 지나도 여섯 윤곽 유지. 일시적 기능이 꺼져 있으면 정지 후 새 변화 수집 없음.
- 초기화 확인창의 취소는 기록 보존, 확인은 계속 유지 기록과 형상 제거.
- 현재 경로의 RGB 코드·투명도·선 두께 편집, 적용 전 초안 유지, 작은 창으로 크기 변경 후 적용.
- 잘못된 색 코드는 적용 비활성화. 외형 변경은 이미 그린 윤곽에도 반영.
- 두 트레일을 다른 색으로 저장하고 함께 렌더링. 두 저장본의 윤곽 경계가 저장 전 경로와 정확히 일치.
- 앞선 저장본을 삭제해도 남은 저장본의 윤곽 크기·위치가 바뀌지 않음.
- 계속 유지 경로를 숨겨도 비교본은 표시. 저장본별 이름/외형 수정, 숨기기/보이기, 삭제 취소/확인.
- 비교본 개수·위치 한도에서 기존 자료 보존, 목록 데이터와 저장 복원 검사.

스크린샷은 `docs/screenshots/`에 있습니다. 실제 게임 결과이며 예시로 만든 이미지가 아닙니다.

## 환경과 한계

- Windows / Java 25 / Gradle 9.5.1
- Minecraft Java 26.2 / Fabric Loader 0.19.5 / Fabric API 0.160.0+26.2
- 별도 생성한 개발용 싱글플레이 테스트 월드
- OpenGL / NVIDIA RTX 3060 / 1000×700 및 854×480 창

아래 항목은 별도 실기 검증을 하지 않았습니다.

- 외부 멀티플레이 서버의 지연·거절·보호 구역, 서버 간 이동 및 차원 이동의 실제 입력 전체 흐름.
- 모든 종류의 피스톤·중계기·비교기·관찰자 회로, 사용자 프로필에 직접 설치 후 게임 프로세스를 다시 시작하는 흐름.
- 두 경로와 최대 비교본의 동시 최악 부하, 목록의 여러 페이지를 실제 입력으로 넘기는 경우.
- 모든 GUI 배율, 다른 렌더링 모드·셰이더·Vulkan.
- 저장 권한 거절/디스크 부족의 실제 게임 환경.

서로 다른 싱글플레이 월드 이동과 이전 월드 재진입, 저장 자료 재읽기를 검사했습니다. 게임 프로세스 재시작 실기 검사로 간주하지 않습니다.
개발용 인증 계정의 Realms/프로필 키, Windows 성능 카운터 및 기본 그래픽 옵션 경고가 있었으나 모드 검사는 통과했습니다.
